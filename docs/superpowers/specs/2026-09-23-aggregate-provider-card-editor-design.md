# 聚合路由编辑器：供应商卡 + 固定档位行（2026-09-23）

## 背景与目标

初版聚合编辑器以「槽位」为单位：每槽一张卡（档位下拉 + 供应商下拉 + 上游模型 +
显示名 + 1M 开关）。用户验收后提出两点：

1. 「获取模型列表」按钮挤在「上游模型」的标签行里，导致该列标签行偏高、
   与「显示名」两列输入框起点错位。
2. 同一家供应商的每个模型都要单独建槽、重复选供应商；用户的心智模型是
   「一家供应商一张卡，卡内按档位填模型」——四档里映射几个就有几个。

目标：编辑器改为**按供应商分组**的卡片视图，同时保持数据结构与后端完全不变。

## 设计决策

### 数据层零改动（核心）

存储仍是扁平的 `AggregateRoutes.slots[]`（`types.ts`），后端 `aggregate.rs`、
profile 的 `inferenceModels` 派生、ID 池校验、表单提交路径（显示名落定）
全部不动。**分组是纯渲染层概念**：载入时 `groupSlotsByProvider` 按供应商分组，
提交时 `flattenProviderGroups` 按「卡序 × 档位序」展平。存量数据零迁移。

### 视图结构（方案 B，用户确认）

```
[默认目标 ………………………………………………………]
┌──────────────────────────────────────────────┐
│ [目标供应商 Select____] [获取模型列表] [🗑 删卡] │   ← 卡头，每卡一次拉模型
│  fable  [上游模型____▾] [显示名____] [1M ⬤] [ID] │
│  opus   [上游模型____▾] [显示名____] [1M ○] [ID] │   ← 固定四行，从强到弱
│  sonnet [上游模型____▾] [显示名____] [1M ○] [ID] │
│  haiku  [上游模型____▾] [显示名____] [1M ○] [ID] │
└──────────────────────────────────────────────┘
[+ 新增供应商]
```

- **行语义**：上游模型非空 = 该档已映射（槽位存在）；清空 = 移除。
  显示名与 1M 开关在未映射行置灰。
- **列头**：卡列表上方一行共用列头（档位 | 上游模型 | 显示名 | 1M 上下文），
  对齐普通供应商「模型映射」表格的样式。
- **槽位 ID 不常显**：纯内部代号（Claude Desktop 选择器的真名 + 代理分流键），
  不占版面；悬停任意一行可见 title 提示，排查代理日志 `request_model` 时用。
- **一家供应商至多一张卡**：卡头 Select 排除其他卡已用的供应商；
  全部占满时「新增供应商」禁用。存量数据引用已删除供应商时保底显示原名。
- **空卡**（选了供应商还没填任何模型）：slots 里没有它的痕迹，由组件本地
  `pendingProviders` 状态记住，避免重渲染时消失。
- **三列对齐**：按钮上移卡头后，行内只剩等高的输入框与开关，错位自然消失
  （初版的行尾 ID 预览列在用户反馈后撤除，见上）。

### 纯函数与测试（`aggregateRoutes.ts`）

- `TIER_ROW_ORDER = ["fable","opus","sonnet","haiku"]`：行序即展平序，ID 分配确定。
- `groupSlotsByProvider`：卡序 = 供应商首次出现顺序；同供应商同档位的存量重复
  取首个（新 UI 造不出重复，仅归一旧数据）。
- `flattenProviderGroups`：卡序 × 档位序重建扁平数组，未映射档位不产出。
- 单测 6 例新增（分组保序、重复归一、展平确定性、空列表、映射数、行序常量），
  既有 20 例（ID 池、厂商词黑名单、默认目标跟随）不动。

### i18n

zh/en：新增 `aggregate.addProvider`、`aggregate.upstreamModelPlaceholder`
（"留空 = 不映射该档"）；删除 `aggregate.addSlot`、`aggregate.tier`
（均不再被引用）。ja/zh-TW 无 aggregate 键（回落 en），不动。

## 显式排除

不加拖拽排序、不加删卡确认、不加组件测试（聚合功能沿用「纯函数单测 + 实机验收」
的既有惯例）；`ClaudeDesktopProviderForm.tsx`、`types.ts`、后端全部不动。

## 验证

- `pnpm typecheck` ✓；`vitest` 26 例全绿 ✓；prettier ✓
- 部署后（md5 与构建产物一致）：`/v1/models` 返回全部 5 个槽位 ID，数据面无回归
- 实机验收口径：打开 Test 供应商应见 3 张卡（智谱 2 档、DeepSeek 2 档、火山 1 档）；
  行内三列等高平行；清空一档保存后槽位减少、路由与 profile 不回归
